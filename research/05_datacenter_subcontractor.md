# SEG005: データセンター建設サブコン（電気・空調設備工事）
調査日: 2026-07-03

## サマリー
電気設備工事（電設サブコン）大手・空調設備工事大手はいずれもデータセンター向け工事の急拡大を追い風に、2025〜2026年3月期決算で軒並み増収増益・過去最高益を記録している。電気設備工事では、きんでん・関電工・クラフティア（旧九電工）・住友電設・日本電設工業が首都圏再開発案件と並びデータセンター関連工事の受注を明示的に決算資料で言及。空調設備工事では、高砂熱学工業・ダイダン・新日本空調・三機工業がデータセンター向け精密空調・液冷対応技術を武器に受注高・繰越工事高で過去最高を更新している。非上場の東洋熱工業もデータセンター向け冷却技術製品を持つが、財務開示が限定的なため確度は中程度にとどまる。全体として「AI・半導体・データセンター」は各社が決算説明資料で明示する主要成長ドライバーの一つとなっている。

## 企業一覧

### きんでん（上場、東証プライム・1944、日本）
- 成長ドライバー: データセンター・物流施設向け一般電気工事の受注が急拡大し、一般電気工事部門の受注高が前年同期比21.0%増の3,194億円に達した。
- 確度: 高
- 根拠: 2026年3月期決算で売上高7,507億円（前期比6.5%増）、営業利益902億円（同48.0%増）、純利益694億円（同47.0%増）を計上。データセンター・物流施設・再エネ関連の建設需要増が一般電気工事の伸長要因として決算資料に明記されている。
- 出典: [きんでん 決算補足資料｜IRライブラリ](https://www.kinden.co.jp/ir/library/supplementary/) きんでん公式IR、[26年1Q決算メモ](https://note.com/asuta_insight/n/n5631bc3b9718) 2026年

### クラフティア（旧九電工）（上場、東証プライム・福証・1959、日本）
- 成長ドライバー: 首都圏再開発・関西統合型リゾートと並びデータセンター関連工事を中心に受注活動を強化し、中間期受注高が前年同期比20.8%増の2,752億円に拡大。
- 確度: 高
- 根拠: 2026年3月期第2四半期決算短信で受注高275,256百万円（前年同期比+20.8%）を開示。2030年3月期を最終年度とする中期経営計画では、データセンター・蓄電池事業への少額出資により工事受注を安定的に獲得する方針を掲げ、連結経常利益を25年3月期比35%増の600億円とする目標を設定。2025年10月に社名を九電工からクラフティアに変更。
- 出典: [2026年３月期 第２四半期（中間期）決算短信](https://www.kraftia.co.jp/ir/docs/2025_251031_tanshin.pdf) クラフティア公式IR 2025-10-31、[九電工社長、蓄電池やデータセンター「出資で工事受注拡大」](https://www.nikkei.com/article/DGXZQOJC29B7I0Z20C25A8000000/) 日本経済新聞 2025-08頃

### 関電工（上場、東証プライム・1942、日本）
- 成長ドライバー: データセンター・半導体工場向け電気設備工事とビル再開発案件の受注拡大により、2026年3月期は連続最高益を更新する見通し。
- 確度: 高
- 根拠: 2025年4〜12月期の連結純利益は前年同期比45%増の462億円と過去最高。2026年3月期通期予想は売上高7,800億円（前期比5.1%増）、営業利益900億円（同8.3%増）で最高益見通し。決算説明資料で「AI・半導体・データセンター」を成長ドライバーの一つに明記。
- 出典: [関電工の好調な営業利益 データセンター向け受注が拡大](https://news.livedoor.com/topics/detail/29720631/) 2025-10-06、[決算情報等 2025年度（2026年3月期）](https://www.kandenko.co.jp/ir/settled-account/2025/) 関電工公式IR

### ダイダン（上場、東証プライム・1980、日本）
- 成長ドライバー: データセンター新設に伴う大型空調工事案件の急増により受注工事高が前年同期比25.5%増の3,531億円（約718億円増）に拡大。
- 確度: 高
- 根拠: 2026年3月期決算で売上高2,562億円（前期比2.5%減）ながら営業利益344億円（同49.7%増）と収益性改善による大幅増益を達成。半導体・車載用蓄電池・データセンター向け精密空調工事の直接受注増が要因として開示資料・IR説明で言及されている。
- 出典: [売上3%減なのに営業利益62%増――ダイダン2026年3月期第3四半期決算](https://note.com/toushihachirou78/n/n1ed805d4ec5f) 2026年、[産業施設向け需要増で過去最高業績予想](https://www.kabutecho.com/interview/) 株主手帳オンライン 2026年

### 高砂熱学工業（上場、東証プライム・1969、日本）
- 成長ドライバー: AI・半導体・データセンター特需を独占的に取り込み、Rapidus千歳IIM採用など先端顧客との直接取引拡大により4期連続で過去最高益を更新。
- 確度: 高
- 根拠: 2026年3月期決算短信（2026年5月12日開示）で売上高4,239億円（前期比+11.1%）、営業利益477億円（同+47.3%）を計上。2027年3月期の予想受注高は3,800億円。半導体クリーンルーム・AIデータセンター冷却など高難易度空調案件の直接受注が採算改善に寄与。
- 出典: [2026年３月期 決算短信〔日本基準〕（連結）](https://finance-frontend-pc-dist.west.edge.storage-yahoo.jp/disclosure/20260512/20260511522999.pdf) 高砂熱学工業 2026-05-12、[売上＋22％・利益＋152％で過去最高（2Q決算解説）](https://note.com/tousi525/n/n296f25ad3540) 2025-11

### 新日本空調（上場、東証プライム・1952、日本）
- 成長ドライバー: 半導体クリーンルーム・データセンター向けを含む「産業」セグメントの完成工事高が全体の57%超を占め、受注高・繰越高とも第2四半期として過去最高を更新。
- 確度: 高
- 根拠: 2026年3月期第2四半期決算で受注高1,056億円（前年同期比+33.3%）、繰越高1,666億円（同+24.2%）、営業利益53.8億円（同+116.1%）、純利益39.8億円（同+112.3%）を計上。2025年度は産業セグメント（半導体含む）の完成工事高が787億円（構成比57.2%）。
- 出典: [新日本空調 決算関連レポート](https://www.fisco.co.jp/wordpress/wp-content/uploads/FISCO/snk20251224.pdf) FISCO（会社四季報アナリストレポート） 2025-12-24、[決算短信・決算説明会資料](https://www.snk.co.jp/ir/library/) 新日本空調公式IR

### 三機工業（上場、東証プライム・1961、日本）
- 成長ドライバー: データセンター向け大容量空調システム「L-LAC」等の技術優位性を背景に、都市再開発・EV電池工場と並ぶ大型案件受注が続き、営業利益が1983年の連結決算開始以降で過去最高を更新。
- 確度: 高
- 根拠: 2025年3月期決算で売上高2,531億円（前期比14.1%増）、営業利益219億円（同88.9%増、過去最高）。受注高2,650億円（同14.0%増）、次期繰越高2,107億円（前期末比5.9%増、過去最高）。決算説明会でデータセンター・EV関連工場向け大型案件の複数受注が利益率改善要因として説明されている。
- 出典: [三機工業、2Qは大型案件の寄与により利益率が大幅改善（決算説明会Q&A）](https://finance.logmi.jp/articles/380513) ログミーファイナンス 2025年、[L-LAC（データセンタ向け空調システム）](https://www.sanki.co.jp/service/technology/article/detail023.html) 三機工業公式サイト

### 住友電設（上場、東証プライム・1949、日本）
- 成長ドライバー: 国内外の大型データセンター案件の進捗と再生可能エネルギー関連工事の好調により、営業利益が前期比42.5%増と大幅増益を達成。
- 確度: 高
- 根拠: 2025年3月期連結決算で売上高2,036億円（前期比9.8%増）、営業利益179億円（同42.5%増）。一般電気工事部門は前期の大型データセンター案件受注の反動で受注高124,012百万円（同10.4%減）となったが、手持工事の進捗により売上高は122,335百万円（同10.1%増）に伸長。2026年3月期は売上高2,100億円（同3.1%増）を予想。
- 出典: [住友電設 財務ハイライト](https://www.sem.co.jp/ir/highlight/) 住友電設公式IR、[決算:住友電工の純利益65％増](https://www.nikkei.com/article/DGXZQOUF035VE0T00C26A2000000/) 日本経済新聞 2026年（親会社住友電工の決算に住友電設株売却益の記載あり）

### 日本電設工業（上場、東証プライム・1950、日本）
- 成長ドライバー: 鉄道会社の設備投資拡大に加え、民間データセンター向け投資の拡大により一般電気工事分野で受注・売上を伸ばし、受注高・売上高・営業利益とも過去最高を更新。
- 確度: 中
- 根拠: 第3四半期連結決算で売上高125.0億円規模（前年同期比+6.4%）、営業利益37.1億円（同+17.3%）、純利益28.9億円（同+14.8%）を計上（四半期累計値、詳細な絶対額はIR資料で要確認）。一般電気工事部門でデータセンター向け営業活動を強化し受注拡大を目指す方針が決算資料に記載されているが、データセンター単独での定量的な受注額の開示は確認できなかった。
- 出典: [日本電設工業 統合報告書2025](https://www.densetsuko.co.jp/pdf/company/sustainability/integrated-report/2025/integrated-report-complete.pdf) 日本電設工業公式 2025年、[サブコン銘柄、相次ぎ上場来高値 データセンターなど需要強く](https://www.nikkei.com/article/DGXZQOUB298PB0Z21C25A0000000/) 日本経済新聞 2025-10頃

### 東洋熱工業（非上場、－、日本）
- 成長ドライバー: データセンター向け高効率冷却ユニット「グリーンアイル」等の独自技術を保有し、生成AI普及に伴う空調・冷却需要拡大の恩恵を受ける立場にあるが、データセンター向け受注の定量開示は限定的。
- 確度: 中
- 根拠: 非上場のため決算短信は非公開だが、官報決算公告によれば売上高約794億円（前期比+9.1%）、純利益約65億円（前期比+111.7%）と増収増益。NECら大手と共同で高効率省エネ型データセンターモジュールや「グリーンアイル」冷却ユニットを開発・製品化しているが、データセンター事業単独の売上・受注実績は公表資料からは確認できなかった。
- 出典: [東洋熱工業株式会社 第88期決算公告](https://catr.jp/companies/1c0a4/17809/settlements/40981/414569) 官報決算データベース、[データセンター用高効率冷却ユニット「グリーンアイル」をプレス発表](https://www.tonets.co.jp/news/tabid/72/Default.aspx?itemid=23&dispmid=627) 東洋熱工業公式サイト
